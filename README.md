📊 Data-Driven Cybersecurity using Machine Learning

A collection of data-driven cybersecurity projects focused on applying Machine Learning techniques to
detect and analyze malicious activities such as network intrusions, botnet traffic, and spam communication.

This repository is designed as a research-oriented, reproducible framework for comparing multiple ML models 
across different security domains.

🧠 Methodology

Each project in this repository follows a consistent pipeline:

🔹 a. Data Collection & Preprocessing
     Handling missing values

     Encoding categorical features

     Feature scaling

🔹 b. Exploratory Data Analysis (EDA)
 
     Distribution analysis

     Correlation analysis

     Class imbalance detection

🔹 c. Model Training

     ultiple machine learning models are trained and compared:

     Logistic Regression (LR)

     Decision Tree (DT)

     Random Forest (RF)

     XGBoost (XGB)

     Deep Neural Network (DNN)

🔹 d. Evaluation Metrics

     Accuracy

     Precision, Recall, F1-score

     ROC-AUC

     Confusion Matrix

🔹 e. Model Complexity Analysis

     Parameter count

     Training time

     Inference time

📂 Projects Included

🔹 1. Network Intrusion Detection

     Dataset: NSL-KDD / CICIDS

     Objective: Detect normal vs malicious traffic

     Type: Binary / Multi-class classification
