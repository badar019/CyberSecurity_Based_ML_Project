Problem Statement

With the rapid growth of internet usage and networked systems, organizations are increasingly vulnerable to various types of cyber attacks. Intrusion Detection Systems (IDS) play a critical role in identifying malicious activities within network traffic and protecting systems from potential security breaches. Traditional rule-based detection systems often struggle to identify new or evolving attack patterns.

The objective of this project is to develop a Machine Learning–based Network Intrusion Detection System using the NSL-KDD dataset. The system will analyze network traffic features and classify each connection into one of the following categories:

Normal traffic

Denial of Service (DoS) attacks

Probe attacks

Remote to Local (R2L) attacks

User to Root (U2R) attacks

Multiple machine learning and deep learning models, including Logistic Regression, Decision Tree, Random Forest, XGBoost, and Deep Neural Networks (DNN), will be trained and evaluated to determine the most effective model for intrusion detection.

The models will be evaluated using performance metrics such as Accuracy, Confusion Matrix, ROC Curve, and AUC Score to compare their ability to correctly detect and classify different types of network attacks.

The goal of this project is to identify the most accurate and efficient model for detecting network intrusions, thereby demonstrating how machine learning techniques can enhance cybersecurity defense mechanisms.
